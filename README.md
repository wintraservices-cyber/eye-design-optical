# Eye Design Optical Clinic — demo concept (ArrowheadX)

Static demo for Eye Design Optical Clinic, 19B Pontiac St., West Fairview, Quezon City.

- `index.html` — animated demo: eye-chart hero ("Which is clearer, 1 or 2?" lens flip, tap to switch), "we've moved" banner from Robinsons Novaliches, services, 6-question self-check, booking request slip with send animation, map with the Panko landmark, FAQ, scripted 24/7 chat. Respects reduced motion.
- `compare.html` — today (Facebook page only, stale Robinsons Novaliches listing) vs. demo, plus the Fairview eye care landscape. Sources listed on the page.
- `pitch.html` — three-step plan modeled on the DCAM Optical build (website + intake + staff dashboard, Messenger/chat assistant, growth and reporting).
- All pages are noindex (meta, `X-Robots-Tag`, robots.txt).

## Demo limits
- The booking form and chat send nothing. In production, requests go to a staff dashboard with an email alert; chat runs on the ArrowheadX Messenger AI.
- Chat replies are keyword-matched, not AI.

## Confirm with the owner before launch
- Clinic hours (not shown on the demo on purpose)
- Services list and any prices
- That the previous branch was Robinsons Novaliches (from a ClickTheCity listing)
- Walk-ins welcome, kids' checks, repairs while you wait, 20–30 minute exam time
